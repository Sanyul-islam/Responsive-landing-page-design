## 📖 About The Project

**Responsive Landing Page Design** is a collection of three separate landing page projects brought together into a single website.

Each landing page has its own HTML, CSS, JavaScript, and assets. The main `index.html` integrates all three pages using HTML iframes, allowing them to appear sequentially on one website.

This project demonstrates responsive web design, reusable project organization, and iframe integration.

## ✨ Features

- 📱 Responsive landing page layouts
- 🎨 Three independent landing page designs
- 🧩 iframe integration for combining separate HTML pages
- 📂 Organized folder structure for each landing page
- 🖼️ Individual assets and stylesheets
- ⚡ Lightweight and fast-loading static website
- 🌍 Live deployment with Vercel

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension for VS Code

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Sanyul-islam/Responsive-landing-page-design.git
```

**2. Navigate to the project directory**

```bash
cd Responsive-landing-page-design
```

**3. Open the project in VS Code**

```bash
code .
```

**4. Run the project**

Open the root `index.html` file and select **Open with Live Server**.

The website will open in your default browser.

## 🔗 How It Works

The root `index.html` acts as the main container and embeds the three landing pages using iframes.

```html
<main>
  <section>
    <iframe src="./page1/index.html" title="Landing Page 1"></iframe>
  </section>

  <section>
    <iframe src="./page2/index.html" title="Landing Page 2"></iframe>
  </section>

  <section>
    <iframe src="./page3/index.html" title="Landing Page 3"></iframe>
  </section>
</main>
```

Each landing page maintains its own HTML structure, CSS styles, JavaScript functionality, and assets.
